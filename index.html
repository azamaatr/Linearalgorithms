01 / ОҚУ БӨЛІМІ

Сызықтық алгоритмдер

Командалар бірінен кейін бірі ретімен орындалады.

Программалауда алгоритмдердің үш негізгі құрылымы бар: сызықтық, тармақталған және циклдік. Бұл сабақта сызықтық алгоритмді қарастырамыз.

Сызықтық алгоритм — тармақталу мен қайталану әрекеттері жоқ, командалары табиғи ретпен бір реттен орындалатын алгоритм.

Кітаптағы мысал

Python 3
a = 5
b = a * 7
c = b % 3
print(c)
Кодты қадаммен орындау үшін батырманы бас.

Қалай есептеледі?

  1. a = 5: a айнымалысына 5 мәні беріледі.
  2. b = a * 7: 5 × 7 = 35, сондықтан b = 35.
  3. c = b % 3: 35-ті 3-ке бөлгендегі қалдық 2.
  4. print(c): экранға c мәні шығады.
НӘТИЖЕ
2
Сызықтық программаның негізгі реті: мәлімет енгізу → есептеу → нәтижені шығару.

03 / ОҚУ БӨЛІМІ

Математикалық өрнекті жазу

Көбейту таңбасын анық жазып, алым мен бөлімді жақшаға аламыз.

Математикалық өрнек:

|a + 2c|b² + 3ac × a × (3 + (4 − a²))

Оны Python тілінде былай жазамыз:

Python 3
y = abs(a + 2*c) / (b**2 + 3*a*c) * a * (3 + (4 - a**2))

Толық программа

Python 3
a = float(input())
b = float(input())
c = float(input())

numerator = abs(a + 2*c)
denominator = b**2 + 3*a*c
y = numerator / denominator * a * (3 + (4 - a**2))

print(y)

float(input()) нақты санды енгізуге мүмкіндік береді. a, b, c мәндерін бөлек жолдарға енгіземіз.

Қадамa = 4, b = 5, c = 1 үшін
Алым|4 + 2 × 1| = 6
Бөлім5² + 3 × 4 × 1 = 37
Соңғы жақша3 + (4 − 4²) = −9
Өрнек(6 / 37) × 4 × (−9) = −216 / 37
НӘТИЖЕ
-5.837837837837839

Блок-схема

Блок-схема алгоритмнің әрекеттерін көрнекі түрде көрсетеді.

Есеп: қабырғалары a және b болатын тіктөртбұрыштың периметрін табу. Формула: P = 2 × (a + b).

Басы
↓
a, b енгізу
↓
P = 2 × (a + b)
↓
P шығару
↓
Соңы

Сәйкес программа

Python 3
a = int(input())
b = int(input())
P = 2 * (a + b)
print(P)
Мысал: a = 5, b = 7 болса, P = 24.

Блоктардың мағынасы

  • Дөңгеленген блок — алгоритмнің басы немесе соңы.
  • Параллелограмм — мәлімет енгізу немесе шығару.
  • Тіктөртбұрыш — есептеу, меншіктеу әрекеті.
  • Бағыттауыш — әрекеттердің орындалу реті.
05 / ОҚУ БӨЛІМІ

Санның цифрларымен жұмыс

// арқылы бүтін бөліндіні, % арқылы қалдықты табамыз.

Тапсырманы алдымен өзің есептеп көр.

Python 3
a = 486
x = a // 100
y = (a // 10) % 10
z = a % 10
b = x * 100 + z
print(b)
Қадамдық талдауды ашу
  1. x = 486 // 100 = 4 — жүздік цифры.
  2. y = (486 // 10) % 10 = 48 % 10 = 8 — ондық цифры.
  3. z = 486 % 10 = 6 — бірлік цифры.
  4. b = 4 × 100 + 6 = 406.
НӘТИЖЕ
406
y есептеледі, бірақ соңғы өрнекте қолданылмайды. Программада ондық орны нөл болып қалады. Нәтиже 46 емес, 406.

Берілгені: Үш жүк көлігінің сыйымдылығы: a = 8.5, b = 8.25, c = 7.25 тонна. Әр көлік бір күнде N рет қатынайды. P күнде тасылған жалпы топырақ массасын және бір көліктің бір күнде таситын орташа массасын тап. N және P — оң бүтін сандар.

ЕНГІЗУ МЫСАЛЫ
4
5
КҮТІЛЕТІН НӘТИЖЕ
480.0 32.0
Жауапты көру
Толық Python коды
N = int(input())
P = int(input())
a = 8.5
b = 8.25
c = 7.25
K = N * P * (a + b + c)
D = N * (a + b + c) / 3
print(K, D)
